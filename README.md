## How I build AI systems

- **Measure before tuning:** golden sets and test sets decide what changes ship.
- **Guard the edges:** out-of-scope refusals, read-only SQL and human approval for risky steps.
- **Trace every query:** latency and cost per request in Langfuse.
- **Ship in containers:** FastAPI services in Docker on AWS, with CI/CD.
